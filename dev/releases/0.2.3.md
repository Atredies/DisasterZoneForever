# DisasterZone 0.2.3 for WoW Forever (updates in game, and Discord)

An update for **&lt;Casual Disaster&gt;**'s guild addon on **WoW Forever** (client 1.60.1, Interface 16001).
**Everyone should install this one: it is the last version you need to download.** From here on, new versions reach
you in game from your guildmates, and you type `/dz update` to install them.

## Install / update

Step-by-step guide with pictures of the folder layout:
**[README](https://github.com/Atredies/DisasterZoneForever#readme)**. In short:

1. Download **`DisasterZone-0.2.3.zip`** below (under *Assets*).
2. Close the game.
3. Delete the old `DisasterZone*` folders from `World of Warcraft\_forever_\Interface\AddOns`, then unzip the new zip
   there, so the `DisasterZone` folder sits directly in `AddOns` (`...\AddOns\DisasterZone\DisasterZone.toc`).
4. Start the game. On the character screen, check that DisasterZone is ticked under **AddOns**. In game,
   `/dz version` shows which version everyone runs.

Your settings, BiS lists, recruitment message and game progress are kept (they live in your saved variables, not in
these folders).

## What changed since 0.2.2

- **Updates in game.** When a guildmate online has a newer version, your copy downloads it in the background and
  tells you. Type **`/dz update`** to install it (the interface reloads). `/dz update` also asks the guild for the
  newest version at any time. Only updates signed with this project's key are accepted.
- **The guild's Discord bot works with Forever.** Raids, sign-ups and BiS lists show in Discord, and sign-ups or
  BiS changes made in Discord reach the game. You don't need anything for that: they reach everyone's addon through
  any guildmate who runs the launcher.

## Discord on your own PC (optional)

1. Download the launcher below: **`DisasterZone-Forever-Launcher_0.5.0_x64-setup.exe`** (Windows) or the **`.AppImage`**
   (Linux). Windows says the publisher is unknown: click **More info > Run anyway**.
2. In the launcher's **Settings**, pick your World of Warcraft folder (the one that holds `_forever_`).
3. In the guild's Discord, type `/launcher` and paste the code under **Link this launcher**.
4. Once: `/character` in Discord to add your character (or just press a raid's sign-up button).

The launcher doesn't install or update the addon yet; it only syncs with Discord.

## Hidden on Forever (for now)

- Gear sim, My Log, the strategy boards, meters and boss mods: Forever gives addons no combat log.

## Something wrong?

Report it in game: **`/dz bug`** (the last Lua error goes with it), **`/dz idea`** for ideas, **`/dz feedback`** to see
every report and its answers. Say what you were doing and where.
