# DisasterZone 0.2.1 for WoW Forever (fixes from the first guild test)

A small update to 0.2.0 for **&lt;Casual Disaster&gt;**'s guild addon on **WoW Forever** (client 1.60.1, Interface 16001).
It fixes what the first test with guildmates found. **Everyone should update:** a 0.2.0 copy still drops items from
Forever's new dungeons when it receives them from someone else (BiS lists, rolls).

## Install / update

Step-by-step guide with pictures of the folder layout:
**[README](https://github.com/Atredies/DisasterZoneForever#readme)**. In short:

1. Download **`DisasterZone-0.2.1.zip`** below (under *Assets*).
2. Close the game.
3. Delete the old `DisasterZone*` folders from `World of Warcraft\_forever_\Interface\AddOns`, then unzip the new zip
   there, so the `DisasterZone` folder sits directly in `AddOns` (`...\AddOns\DisasterZone\DisasterZone.toc`).
4. Start the game. On the character screen, check that DisasterZone is ticked under **AddOns**. In game,
   `/dz version` shows which version everyone runs.

Your settings, BiS lists, recruitment message and game progress are kept (they live in your saved variables, not in
these folders).

## What changed since 0.2.0

- **Items from Forever's new dungeons work everywhere.** Their item numbers are higher than any TBC item, and the
  addon refused them: `/dz roll [item]` printed its help line instead of starting the roll, My BiS would not take
  them (for example from the "Loot (boss not confirmed)" lists), and the loot log, council and sync dropped them.
- **List a group > Dungeon fits the window.** Forever's level bands hold six dungeons: the tiles now share the row
  instead of running past the window's edge, long names are shortened (BRD, LBRS, DM: East, Strat: UD...) with the
  full name in the tooltip, and every level band has its picture again.

## Still to test

## Hidden on Forever (for now)

- Gear sim, My Log, the strategy boards, meters and boss mods: Forever gives addons no combat log.
- **In-game updates are off.** We do not have our own signing keys yet, so every new version is a new zip on this
  page.

## Something wrong?

Report it in game: **`/dz bug`** (the last Lua error goes with it), **`/dz idea`** for ideas, **`/dz feedback`** to see
every report and its answers. Say what you were doing and where.
