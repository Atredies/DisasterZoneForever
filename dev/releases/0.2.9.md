# DisasterZone 0.2.9 for WoW Forever (guildmates and professions back)

An update for **&lt;Casual Disaster&gt;**'s guild addon on **WoW Forever** (client 1.60.1, Interface 16001).

**Already on 0.2.3 or newer? You don't need this download.** 0.2.9 reaches you in game: type **`/dz update`**.
This zip is for anyone installing fresh or who can't get the update in game. It is 0.2.3 with in-game update #6
already in it, so later in-game updates keep reaching you too.

## Install / update

Step-by-step guide with pictures of the folder layout:
**[README](https://github.com/Atredies/DisasterZoneForever#readme)**. In short:

1. Download **`DisasterZone-0.2.9.zip`** below (under *Assets*).
2. Close the game.
3. Delete the old `DisasterZone*` folders from `World of Warcraft\_forever_\Interface\AddOns`, then unzip the new zip
   there, so the `DisasterZone` folder sits directly in `AddOns` (`...\AddOns\DisasterZone\DisasterZone.toc`).
4. Start the game. On the character screen, check that DisasterZone is ticked under **AddOns**. In game,
   `/dz version` shows which version everyone runs.

Your settings, BiS lists, recruitment messages and game progress are kept (they live in your saved variables, not in
these folders).

## What changed in 0.2.9

- **Guildmates see each other again; the Professions page is back.** The game's 20 November update (build 71037)
  stopped telling addons the realm name, and DisasterZone lost track of the guild's saved data: members, recipes,
  raids, recruits. It now uses the guild's realm when the game gives none, so everything comes back as it was.
- **Recruitment:** only whispers about the guild (guild, recruit, apply, ginv, the guild's name) add someone to
  Recruitment after a post. Dungeon group whispers ("inv pls") stay out.
- **Download link:** `/dz download` (or `/dz link`) and Settings > About give the link to copy for a friend.

## Since 0.2.6 (0.2.7 and 0.2.8)

- **Invite to the guild works again** (Forever blocks addon invites; the dialog sends the game's own `/ginvite`).

## Hidden on Forever (for now)

- Gear sim, My Log, the strategy boards, meters and boss mods: Forever gives addons no combat log.

## Something wrong?

Report it in game: **`/dz bug`** (the last Lua error goes with it), **`/dz idea`** for ideas, **`/dz feedback`** to see
every report and its answers. Say what you were doing and where.
